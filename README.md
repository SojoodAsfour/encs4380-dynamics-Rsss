# ENCS4380 – Dynamic Characteristics Interactive Toolkit

**Course:** ENCS4380 – Interfacing Techniques  
**University:** Birzeit University  
**Instructor:** Dr. Wasel Ghanem  
**Assignment:** Homework 1

## Project Description
An interactive web-based toolkit for exploring the dynamic characteristics of sensors and systems through live simulations, adjustable parameters, and response plots.

## Project Modules
1. **First-Order Time Response** – Step and ramp responses.
2. **First-Order Frequency Response** – Sinusoidal response and Bode plots.
3. **Second-Order Response** – Damping behavior and state-space visualization.
4. **Guess the Sensor** – Interactive sensor identification challenge.
