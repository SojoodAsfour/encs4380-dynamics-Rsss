## About TRANSIENT

TRANSIENT is an interactive educational web toolkit designed to explore the dynamic characteristics of sensors and systems.

The toolkit allows users to experiment with adjustable parameters, visualize system responses in real time, and understand how sensors behave under different input signals.

## Project Modules

1. **First-Order Time Response** – Step and ramp responses, time constant, and steady-state error.
2. **First-Order Frequency Response** – Sinusoidal response, amplitude ratio, phase lag, and Bode plots.
3. **Second-Order Response** – Damping behavior, response metrics, poles, and state-space visualization.
4. **Guess the Sensor** – Interactive sensor identification challenge with randomized parameters and scoring.
